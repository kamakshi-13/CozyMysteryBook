FIRST-TIME SETUP

Prepare Ollama

⌘
  1. Install Ollama on your computer.
  2. Open PowerShell or Terminal and run ollama pull qwen3:4b.
  3. Keep Ollama running, then return here and check the connection.
  4. Generate a booklet. If Ollama is unavailable, the built-in generator can still make a verified draft.

The first generation can take a little longer while the model loads into memory.

What the model creates vs. what the engine verifies

Local LLM

Case facts, suspects, motive, title, story, thematic word list, instructions and gentle hints.

Deterministic puzzle engine

Grid construction, valid puzzle mechanics, solution keys, uniqueness checks and consistency between every clue and the final case.

You, the Keeper
